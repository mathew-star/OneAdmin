# OneAdmin UI

The single-page app served by `AdminSite.mount()`. Users never build it: it ships prebuilt inside the wheel. This README is for contributors.

**Stack (ADR-0011):**
- React 19, TypeScript (strict), Vite 8
- TanStack Router (code-based routes) + TanStack Query
- Tailwind CSS 4 with design tokens in `src/styles.css`
- Radix (`radix-ui`) for overlays, `lucide-react` icons
- Biome, Vitest + Testing Library, Playwright + axe

## Commands
```bash
pnpm install --frozen-lockfile
pnpm dev              # http://localhost:5173/admin/, proxies /admin/api to a FastAPI app on :8000
pnpm test             # unit + whole-app tests (in-memory API, no server)
pnpm lint             # Biome (format + lint, a11y rules on)
pnpm build            # type-check, build to dist/, enforce the bundle budget and CSP rules
pnpm build:install    # build, then copy into ../src/oneadmin/static for editable installs
pnpm test:e2e         # Playwright against tests/e2e/server.py (run build:install first)
pnpm gen:api          # regenerate src/api/openapi.d.ts from openapi.json
pnpm check:api        # fail if openapi.d.ts is stale
```

For `pnpm dev`, run any app that mounts the admin at `/admin` on port 8000, e.g. the pilot in `../backend`. Override the target with `ONEADMIN_DEV_API=http://127.0.0.1:9000`. To try the UI without a database server: `uv run python ../tests/e2e/server.py`, then open `http://localhost:8765/backoffice/` (login `e2e@example.com` / `e2e password 1234`).

## How it fits together
| File | Role |
|---|---|
| `src/config.ts` | Reads the config the server injects into `index.html` (`basePath`, `apiBase`, `title`, `auth`). It is JSON, not JS, so the CSP stays strict. |
| `src/api/client.ts` | The only network code. Non-2xx → `ApiError(code, message, param)`; the CSRF token on unsafe methods. |
| `src/api/queries.ts` | Every cache key and fetcher. The count is cached per *set of matching rows*, so paging doesn't recount. |
| `src/router.tsx` | Routes. `app.beforeLoad` is the single auth gate; model routes 404 for unknown slugs. |
| `src/lib/listSearch.ts` | URL ⇄ API mapping for lists. Search params *are* the API's params (`sort`, `q`, `f.<field>__<op>`, `cursor`, `last`), kept as strings by `lib/searchParams.ts`. |
| `src/lib/format.ts` | Display rules per field kind. Decimals and big integers stay strings, never floats. |
| `src/app.tsx` | Wiring shared by `main.tsx` and the tests. A 401 from any query sends the user to login and back. |

## Rules
- **Types come from the server.**
  - `openapi.json` is generated by `uv run python scripts/export_openapi.py`; a pytest test fails when it is stale.
  - `src/api/openapi.d.ts` is generated from it with `pnpm gen:api`; `pnpm check:api` fails when it is stale.
  - Never hand-write API types.
- **No inline `<script>`/`<style>`, no `style=""` in HTML.** The CSP blocks them, and `scripts/check-bundle.mjs` fails the build.
- **Initial JS ≤ 150 KB gzip** (currently ~135 KB). Anything big and optional goes behind `import()`.
- **No `href="#..."` links.** They resolve against the injected `<base href>` and navigate away.
- **Every page is checked with axe** in the e2e test. New interactive components need keyboard support and labels.
- Use the tokens (`bg-surface`, `text-muted`, `text-accent`, ...), not raw colours, so dark mode keeps working.
